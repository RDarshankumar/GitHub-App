# 🐙 GitView Explorer

A GitHub profile viewer web app that lets users search any GitHub username and view detailed profile info — including repositories, followers, following, and more — using the **official GitHub API**. Built with **React**, **Tailwind CSS**, and powered by real-time data fetching.

---

## 🚀 Features

- 🔍 Search any GitHub username
- 📁 View public repositories
- 👥 Followers and Following lists
- 🧑‍💻 Profile details like bio, company, location, blog
- 📊 Stats: Repo count, stars, gists, etc.
- 🌐 Fully responsive UI using Tailwind CSS
- ⚡ Live data via GitHub REST API

---

## 🛠️ Tech Stack

- React JS
- Tailwind CSS
- GitHub REST API (v3)
- Axios (or Fetch API)
